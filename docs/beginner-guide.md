# Beginner Guide

## What this repository does

This is a reusable research skill library. It helps an AI find evidence, compare sources, explain uncertainty, and produce answers that can be checked.

## Basic workflow

1. Define the question precisely.
2. Search for primary sources first.
3. Collect only evidence relevant to the question.
4. Compare important sources.
5. Mark uncertainty and conflicts.
6. Answer directly and cite claims that need verification.

## Source rule

Prefer official documentation, original research, government material, standards, and direct statements from the relevant organization or author.

Use secondary sources when they add useful analysis, but do not let a summary replace a primary source when the primary source is available.

## Quality rule

Do not make an answer longer just to make it look researched. Keep the evidence needed to support the answer and leave out unrelated material.
