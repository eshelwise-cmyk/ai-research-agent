# Web Research Workflow

A structured process for finding, verifying, and organizing information.

## Workflow

1. Define the question.
2. Find primary sources.
3. Collect evidence.
4. Compare sources.
5. Identify uncertainty.
6. Produce an answer.

## Source Priority

1. Official documentation
2. Academic research
3. Government sources
4. Industry reports
5. Expert analysis
6. General websites
