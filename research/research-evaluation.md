# Research Evaluation Reference

NIST's work on evaluating agentic AI provides a useful external reference for research-agent evaluation, especially for testing whether an agent finds relevant sources and whether cited evidence supports generated claims.

## How to use it

Use the resource as an evaluation reference, not as a requirement to copy a particular benchmark or implementation.

Useful checks:

- Are retrieved sources relevant to the question?
- Does the answer distinguish evidence from inference?
- Does each important citation support the claim it is attached to?
- Can the research process be evaluated consistently?

## Primary resource

NIST: Building Evaluation Probes for Agentic AI

https://www.nist.gov/programs-projects/building-evaluation-probes-agentic-ai
