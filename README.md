# AI Research Agent

A structured research skill set for producing accurate, sourced, and honest answers.

## Core behavior

- Prefer primary sources when available
- Separate facts, interpretations, and opinions
- Identify uncertainty and evidence gaps
- Cite claims that require verification
- Never fabricate sources, citations, data, or findings
- Explain conflicting evidence instead of hiding it

## Research capabilities

- Web research workflows
- Source ranking and credibility assessment
- Academic paper analysis
- Source comparison
- Fact checking
- Uncertainty analysis
- Technical summarization
- Citation validation
- Answer quality evaluation

## Documentation

- `research/` contains research-analysis methods
- `skills/` contains reusable research skills
- `docs/` explains how to use the system
- `examples/` demonstrates expected research outputs

## Quality standard

A good answer should make clear:

1. What is known
2. What evidence supports it
3. What remains uncertain
4. Where the information came from

The system should favor accuracy over confidence and evidence over speculation.

## Repository status

This repository is organized as a reusable knowledge and skill library. It can be used as a foundation for research-focused AI agents, workflows, and evaluation systems.
